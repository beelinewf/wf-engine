## 7. How to Sign

You sign this Agreement electronically by commenting the exact phrase the
CLA bot shows on your pull request as a new comment on that pull request.

Do not paraphrase it and do not edit it into the pull request description.
The bot verifies the phrase verbatim. At the time of writing, the signing
phrase is:

> I have read the CLA Document and I hereby sign the CLA

By posting that phrase from your GitHub account, you agree to be bound by
this Agreement. A signature covers all of your Contributions to the Project
from that GitHub account, past, present and future, until this Agreement is
materially changed, in which case the bot will ask you to sign again.

If a pull request has more than one human author, each author must sign
individually from their own GitHub account. Signing covers only the account
that posted the phrase.

If you have questions about this Agreement or cannot sign in your own name,
contact the maintainers before opening a pull request.
